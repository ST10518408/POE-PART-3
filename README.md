This project is a Java QuickChat messaging system with full user authentication and message management features, supported by JUnit tests to verify its functionality. The program allows users to register and log in with validated usernames, passwords, and South African phone numbers. Once logged in, users can send, store, or disregard messages, where each message is assigned a unique ID and automatically generated hash. The system stores messages in different ArrayLists and supports searching by message ID or recipient, deleting messages by hash, displaying the longest message, counting total sent messages, and generating detailed reports. The JUnit tests ensure all features work correctly by checking login validation, message length rules, recipient formatting, message handling, and correct outputs for sending, storing, and reporting messages.
